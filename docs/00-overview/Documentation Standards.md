## Single Source of Truth Rule

This repository is the official source of truth for FixNest business, product, operations, brand, finance, legal, roadmap, and technology decisions.

Important decisions should not live only in WhatsApp, email, meeting notes, verbal discussions, or scattered Google Docs. If a decision affects strategy, operations, product scope, customers, technicians, money, compliance, or engineering, it must be captured here.

## Required Document Header

Every major document should start with this metadata block:

```markdown
Version: 0.1.0  
Status: Draft  
Owner: Founders  
Last Updated: YYYY-MM-DD
```

## Status Values

- `Draft` — being written or actively shaped.
- `Review` — ready for founder, operator, or advisor review.
- `Approved` — accepted as current operating guidance.
- `Archived` — preserved for history but no longer active.

## Writing Standard

Write every document as if another founder joins next year, a team of 20 engineers starts development, an investor requests due diligence, or FixNest raises funding. Documents should be professional, versioned, interconnected, and clear enough to guide execution without verbal context.
