# FixNest User Stories

Version: 0.1.0  
Status: Draft  
Owner: Product  
Last Updated: 2026-08-02

---

## Homeowner Stories

- As a homeowner, I want to request a home service so that I can get help without searching for random technicians.
- As a homeowner, I want pricing guidance before booking so that I understand likely costs.
- As a homeowner, I want technician assignment details so that I know who is visiting my home.
- As a homeowner, I want service history and invoices so that I can track previous work.
- As a homeowner, I want to raise a complaint if the service fails so that FixNest can investigate and resolve it.

## Technician Stories

- As a technician, I want to receive jobs that match my verified skills and service area.
- As a technician, I want clear job details before accepting so that I can prepare properly.
- As a technician, I want completed work and ratings recorded so that I can build my reputation.

## Operations Stories

- As an operations user, I want to assign technicians based on skill, location, availability, rating, and workload.
- As an operations user, I want to track job status from request to closure.
- As an operations user, I want complaint and refund records so that issues remain traceable.
