This index is the documentation dashboard for FixNest. It shows what exists, where it lives, ownership, maturity, and the recommended reading order.

## Repository Rules

- This repository is the single source of truth for important FixNest decisions.
- Decisions made in chats, calls, emails, or external documents are not official until documented here.
- Every major document must include version, status, owner, and last updated metadata.
- Documents should be written for future founders, operators, engineers, investors, and due-diligence reviewers.
